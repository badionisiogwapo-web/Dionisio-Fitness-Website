SETUP:
1. Extract this folder to:
   C:\xampp\htdocs\

2. Start Apache in XAMPP.

3. Open:
   http://localhost/Dionisio_Fitness_Website_Brand_Guide/

MySQL is not required for this front-end website.

PHOTO SIZE SETTINGS:
Open:
   css/style.css

Near the top is:
   PHOTO SIZE / POSITION SETTINGS

You can adjust:
- .about-image height
- .about-image img object-position
- .product-image height
- .product-image img object-fit
- .gallery-item img object-position
- .hero-image background-position
- .page-banner background-position

IMPORTANT:
The actual image files were not included in the code upload, so place your existing images in the assets folder using the filenames listed there.
